# Student Performance Analysis Using DBSCAN

## Project Overview
This project analyzes student performance using Python and the DBSCAN clustering algorithm. It explores relationships between attendance, assignment marks, internal marks, and exam marks.

## Dataset Features
- Student_ID
- Name
- Attendance
- Assignment_Marks
- Internal_Marks
- Exam_Marks

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- DBSCAN Clustering
- PCA Visualization

## Project Workflow
1. Load the student dataset.
2. Clean and preprocess the data.
3. Perform statistical analysis.
4. Visualize student performance.
5. Scale numerical features.
6. Apply DBSCAN clustering.
7. Visualize clusters using PCA.
8. Analyze noise points and export results.

## How to Run
1. Open the notebook in Google Colab.
2. Upload `student_performance_dataset.csv` when prompted.
3. Run the notebook cells in order.

## Advanced Topic
DBSCAN (Density-Based Spatial Clustering of Applications with Noise) identifies dense groups of students and unusual performance patterns without requiring a predefined number of clusters.
